# Contributing to Phrasa

Thanks for helping make live reading calmer and more dependable.

Before opening a pull request:

1. Keep changes focused and preserve Phrasa's local-first behavior.
2. Never commit credentials, production data, private device evidence, or
   another person's scripts.
3. Run the checks documented in `README.md` for the surfaces you changed.
4. Explain the user problem, the proposed behavior, and the verification you
   performed.

By submitting a contribution, you agree that it may be distributed under the
Apache License 2.0. For security reports, follow `SECURITY.md` instead of
opening a public issue.
